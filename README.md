# Coffeex — приём заказов

Плоская структура — все файлы в одной папке (без css/js/img подпапок).
Сделано намеренно: мобильная загрузка на GitHub расплющивает папки, так что
проще сразу сделать сайт под это, чем бороться с расплющиванием.

## Что нового в этой версии (актуально на сейчас)

- **Кофе — первым в списке** (Espresso Based, затем Latte, Coffee Mix).
- **Dessert убран** полностью.
- **Только самовывоз** — доставку убрали, поле адреса и выбор способа
  получения больше нет. Имя и телефон в предзаказе остались.
- **Автоскидка 10%** при заказе от 15₾.
- **Счётчик лояльности** (5 покупок → 6-я бесплатно) — работает после
  подключения таблицы.
- **Новая категория Latte** — 10 позиций (обычный + 9 вкусов).
- **Milkshake пополнен**: Oreo Banana Shake, Pina Colada.
- **Освежающие напитки пополнены**: Blue Lagoon, Lava Lime, Kiwi Green Apple.
- **Espresso Based пополнен**: Bumble Coffee, Espresso Tonik.
- **Рельсы "Новинки" и "Топ продаж"** — прокрутка сверху меню (как в
  Wolt/Glovo), ссылаются на те же товары, что и в обычных категориях —
  корзина не задваивается, счётчик синхронный в обоих местах.
  - Новинки: Blue Lagoon, Lava Lime, Bumble Coffee
  - Топ продаж: Mojito, Banana Strawberry Smoothie, Ice Latte

```
Code.gs               backend для Google Таблицы — инструкция внутри файла
                       (не часть сайта, вставляется отдельно в Apps Script)
```

## Что нового в этой версии

- **Кофе — первым в списке** (Espresso Based, затем Coffee Mix), остальное
  дальше — это кофейня, и меню теперь так и выглядит.
- **Dessert убран** — таких позиций нет.
- **Автоскидка 10%** при заказе от 15₾ — считается сама, видно в корзине и в
  итоговом чеке, попадает в текст WhatsApp и в Google Таблицу (в комментарии).
- **Счётчик лояльности** (5 покупок → 6-я бесплатно, как на карте, которую
  присылали) — при вводе телефона в предзаказе подтягивает количество прошлых
  покупок этого номера из Google Таблицы и рисует прогресс кружочками.
  **Работает только после подключения таблицы** — до этого просто не виден
  (не показывает нули или неверные данные, честно молчит).

## Деплой на GitHub — см. отдельные пошаговые инструкции в чате

Коротко: создать репозиторий → Add file → Upload files → выделить все файлы
из этой папки сразу → Commit → Settings → Pages → Source: main / root.

## Подключить Google Таблицу

1. Открой `Code.gs` — там инструкция в комментарии наверху.
2. Таблица уже создана: https://docs.google.com/spreadsheets/d/1EZFAdOwqA5junpxrpHixbwAmhpk59fa0wWWPDGdZv8E/edit
3. Расширения → Apps Script (только в браузере на компьютере — в мобильном
   приложении Google Таблиц этого пункта нет физически).
4. Вставь код из `Code.gs`, разверни как веб-приложение (Выполнять как: я,
   Доступ: Все), скопируй `/exec`-ссылку.
5. Вставь эту ссылку в `app.js` вместо `SHEETS_ENDPOINT = 'PASTE_APPS_SCRIPT_EXEC_URL_HERE'`.

## Известные ограничения (честно)

- Сохранение имени/телефона (localStorage) работает только на реальном сайте
  после деплоя, не в превью-песочнице Claude.
- Ссылка на оплату — это реквизиты + кнопка "отметить", не настоящий приём
  платежа. Подтверждает оплату всё равно человек, глядя в приложение банка.
- Отправка в WhatsApp — не автоматическая, открывает готовый текст, отправляет
  человек сам.
- PIN на staff.html — не настоящая защита (статический сайт не может её
  обеспечить), это барьер от случайного клиента, а не от того, кто специально
  полезет в код страницы.
- Фото для Tea/Choco/3in1/Smoothie/Milkshake — эмодзи-иконки, не реальные фото.
- Цена на "Апельсиновый сок" — используется цена со стенда (6₾), не с постера (5₾).
